🔐 Account Access

Provision a clinic account

Passwords are managed by Firebase Authentication and are never stored in the clinic database.

  1. In Firebase Console, open Authentication and enable the Email/Password provider. Add ashraful1625.github.io under Authentication settings → Authorized domains.
  2. Create the staff member's account there and securely give them their temporary password.
  3. Copy the new account's UID. In Firestore, create user_roles/{uid} using that exact UID as the document ID.
  4. Add fields: uid (string, same UID), name (string), role (doctor, staff, or admin), and optionally profileId (the corresponding doctor/staff document ID).
  5. For the first administrator, create the role document in the Firebase Console. Repeat the role-document step there for each account.

To remove access, disable the account in Firebase Authentication and delete its user_roles document. Do not share passwords or grant admin unless required.
